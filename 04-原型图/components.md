# 组件规范 · 网上书店与图书销售系统（NEW-063）

所有组件在 `design/mock.css` 中以类名实现，build 阶段 1:1 复刻到 `frontend/src/styles/theme.css` + Element Plus 主题变量。

## 1. 按钮 `.btn`

| 变体 | 样式 | 用途 |
|---|---|---|
| `.btn.primary` | 底 `#3A5A8C`，字白，边同色 | 提交、保存、进入下一步 |
| `.btn.ghost` | 底 `#EEF2F8`，边 `#CFDAEB`，字 `#3A5A8C` | 查询、导出、次要动作 |
| `.btn` | 底白，边 `#E2E5E8` | 取消、重置、切页 |
| `.btn.danger` | 字 `#B02A37`，边 `#E5C3C7`，底白 | 下架、驳回、整单取消（二次确认） |
| `.btn.gold` | 底 `#C9A227`，字 `#3B2E05` | 强调动作：立即重算、导出报表 |

尺寸：高 32px（`.sm` 24px），内边距 6/14px，圆角 6px，字号 13px，`white-space:nowrap`。

## 2. 输入与筛选

- `.toolbar` 单行排列：搜索框 230px → 下拉 196px → 日期区间 150px → 查询/重置 → 右侧主操作。
- 输入高 32px，聚焦描边 `#6B8CBE` + 3px 光晕。
- 表单 `.fgrid` 两列，标签宽 92px 右对齐；长文本（简介、原因）跨两列（`.full`），`textarea` 行高 20px。

## 3. 表格

- 表头：底 `#F3F5F7`，字 `#5B6770`，13px/500，`white-space:nowrap`，**不定宽**，按内容自适应。
- 单元格：内边距 8/11px，下边框 `#EDF0F3`，行悬浮 `#F8FAFC`。
- 数字列 `.mono`（`tabular-nums`），金额两位小数，库存与数量右对齐。
- 行内操作最多「查看 + 2 个高频动作」，其余进「更多」。
- 所有列表页底部 `.pager`：左「共 N 条 · 每页 M 条」，右页码；后端分页，保留页码与每页条数。

## 4. 标签 `.tag`

| 类 | 底 / 字 | 语义 |
|---|---|---|
| `.t-green` | `#E3F0E9` / `#2B7955` | 已入库、已完成、在售、合格、已采纳 |
| `.t-blue` | `#E8EEF8` / `#33507E` | 待发货、已发货、平销、换货、本部门 |
| `.t-amber` | `#FAF0D9` / `#8A6410` | 待支付、待审核、滞销、待质检 |
| `.t-red` | `#FAE8EA` / `#B02A37` | 缺货、盘亏、驳回、已屏蔽、畅销（红＝热销，符合中文语境） |
| `.t-gray` | `#EDF0F3` / `#5B6A76` | 已取消、已关闭、断销、未采纳 |
| `.t-gold` | `#F7EDCF` / `#7A5C0C` | 强调档位、待补货 |

标签高 19px、圆角 3px、字号 12px；状态必须「颜色 + 中文」双编码。

## 5. 卡片

- `.pcard`：白底、1px 边、8px 圆角、16/18px 内边距；`h3` 15px/600，右侧可放 `<span>` 作计数。
- `.kpi`：顶部 2px `#6B8CBE` 线、标签 12px、数值 24px/600、Delta 11px（涨 `#2B7955`，跌 `#B02A37`）。
  - 8 项指标用 `.kpis.cols8` 单行 8 列（数值压到 19px），避免 6 列换行留白。
- 看板卡片 `.dash .c`：固定行高 + `.cbody{overflow:hidden}`，图表必须能在一屏内画完。

## 6. 图表

| 类型 | 函数 | 用法 |
|---|---|---|
| 双轴折线 | `chart_line(..., dual=True)` | 近 30 天销售额（左轴）+ 订单量（右轴，`max×2.3` 避免重合） |
| 环形 | `chart_donut` | 分类占比、退换原因；中心显示主值 |
| 横向条 | `chart_hbars` | 出版社 TOP10、退换原因占比（窄卡里中文标签不被裁） |
| 纵向柱 | `chart_vbars` | 类目 ≤5 项时使用 |
| 漏斗 | `chart_funnel` | 下单→支付→发货→签收→完成 |
| 直方图 | `chart_hist` | 库存周转天数分布 |
| 堆叠条 | `chart_stack` | 补货等级 × 采纳状态 |
| 分值条 | `score_rows` | 五因子得分（`score-row` 三列：名称+权重 / 条 / 数值） |

规则：类别 >5 项先改横向条或缩写名称，不靠缩字号硬塞；末位 x 轴标签右对齐防裁切；
图表卡片高度按 `content` 实测值定，不用估值凑。

## 7. 流程条与时间轴

- `.flow`：状态胶囊 + `›` 连接；已过 `done`（绿）、当前 `on`（蓝）、未来灰。
- `.timeline`：左侧 1px 竖线 + 圆点；`ok` 绿、`warn` 红；每条含标题 + 「操作人 · 时间」。

## 8. 门户（读者端）

- `.pnav`：白底 62px，品牌（金色方块「书」）+ 5 个导航 + 搜索框 + 购物车角标 + 头像。
- `.hero`：`#FBFAF7` 纸面块 + 1px `#E6E2D8` 边，衬线标题，不用渐变。
- `.bgrid` / `.bk`：5 列封面网格，封面 3:4 左侧 4px 书脊阴影条，书名两行截断，售价红 + 划线定价 + 星级。
- `.sec-t`：衬线 16px 板块标题 + 右侧「查看全部 ›」。

## 9. 移动端

- `.phone` 390×780：状态栏 40px（主色）、页头 50px、内容区浅灰、底部 tab 58px。
- `.mcard`：白卡 8px 圆角，标题行左标题右状态，指标 12px。
- 列表页在 <768px 由表格转卡片：只保留编号、状态、时间与负责人。

## 10. 交互约定（贯穿四阶段）

- 审批 / 流转 / 派单用**右侧抽屉**（`.drawer` 460px，宽表 660px），抽屉内带单据摘要。
- 危险操作红色描边 + 二次确认；普通取消不做强提醒。
- 空状态说明原因与下一步；加载 >300ms 显示局部骨架，禁止整页白屏。
- 日期区间、人员、组织、字典、级联用专用组件，不用文本框代替。

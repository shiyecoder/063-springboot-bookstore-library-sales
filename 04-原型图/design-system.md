# 设计系统 · 网上书店与图书销售系统（NEW-063）

> 视觉方向：**书店纸感** —— 深藏蓝书脊色为主色，米白纸面做底，金色作强调；
> 不用渐变背景，不用玻璃拟态，靠留白、细分割线与衬线标题建立「纸质阅读」气质。

## 1. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 Primary | `#3A5A8C` | 侧栏底色、主按钮、当前菜单、关键数字 |
| 主色深 | `#2C4770` | 登录页左栏（作深色块，非渐变） |
| 辅助色 Secondary | `#6B8CBE` | 次级按钮、图表普通系列、头像底、选中态描边 |
| 强调色 Accent | `#C9A227` | 待办角标、重点提示、图表对比系列、卡片顶部 2px 线 |
| 页面背景 | `#F5F6F7` | 内容区底 |
| 纸面色 Paper | `#FBFAF7` | 门户 hero、价格区块、引文块（仅浅色场景） |
| 正文 | `#1F2933` | 标题与正文 |
| 次要文字 | `#5B6770` / `#8B96A1` | 说明、占位、时间戳 |
| 分割线 | `#E2E5E8`，浅分割 `#EDF0F3` | 表格行、卡片边 |
| 成功 | `#2B7955` | 已完成、已通过、在售、盘盈 |
| 警示 | `#8A6410` | 滞销、待审核、待质检 |
| 危险 | `#B02A37` | 驳回、盘亏、缺货、售价、金额 |

派生规则：图表颜色只从 `#3A5A8C / #6B8CBE / #C9A227 / #94AACB / #D8C48A` 中取，
同一含义跨页面固定，例如「销售额」永远主色、「订单量」永远强调色。
状态一律 **颜色 + 中文标签** 双编码（`.tag`），不靠颜色单独表达。

## 2. 字体阶梯

| 层级 | 字号 / 行高 | 用途 |
|---|---|---|
| H1 | 20 / 28，600 | 页面标题 |
| H2（衬线） | 21–27 / 34–40，600 | 门户 hero、登录标题（`Songti SC, Georgia`） |
| 卡片标题 | 13–13.5 / 20，500–600 | `.c .ct`、`.pcard h3` |
| 正文 | 14 / 22 | 全局 |
| 表格 / 表单 | 13 / 20 | 密集布局 |
| 辅助 | 12 / 18，`#5B6770` | 说明、副标题 |
| 微型 | 10.5–11.5 | 图表轴、角标、卡片元信息 |

数字统一 `font-variant-numeric: tabular-nums`，金额保留两位小数。

## 3. 间距与栅格

- 内容区外边距 **24px**（上下 20px），卡片间距 **12–14px**。
- 侧栏 **220px**、顶栏 **56px**，`.shell{height:100vh;overflow:hidden}`，`.content` 内部滚动 —— 保证 1440×900 下不出现横向滚动、看板一屏。
- 看板 `.dash` 4 列，`grid-auto-rows:303px`，两行共 618px + 12px 间隔 = 630px，加 8 项 KPI 与页头正好 844px。
- 表单：标签固定 92–104px 右对齐，输入 360–520px；搜索下拉 196px（180–240 区间）。

## 4. 圆角、边框与阴影

- 圆角：卡片 8px，按钮 / 输入 6px，标签 3px，封面 2–4px（书要「方」）。
- 边框：一律 1px `#E2E5E8`；不用投影表达层级，只有浮层（`.drawer`）用 `0 -8px 24px rgba(23,34,44,.14)`。
- 选中态：`border-color: var(--secondary)` + `box-shadow: 0 0 0 3px rgba(107,140,190,.16)`。

## 5. 组件规范（摘要，详见 components.md）

按钮 4 类（primary / ghost / danger / gold）+ sm 变体；表格表头浅灰 `#F3F5F7`、行悬浮 `#F8FAFC`；
标签 6 色；分页右对齐；图表 6 类（折线含双轴、环形、横向条、纵向柱、漏斗、直方图、堆叠条）。

## 6. 角色视觉区分

同一套设计令牌，通过侧栏底色深浅与导航分组区分角色，避免「换个项目只换 logo」：

| 角色 | 侧栏底色 | 导航分组 |
|---|---|---|
| 运营管理员 | `#3A5A8C` 主色 | 经营概览 / 图书与分类 / 交易 / 内容 / 补货 / 个人 |
| 书店店员 | `#34507D` | 门店运营 / 订单 / 售后 / 内容 / 个人 |
| 库管员 | `#3A5A8C`（同主色，分组不同） | 库存作业 / 入库 / 库存 / 退货 / 个人 |
| 采购员 | `#35558A` | 补货决策 / 规则 / 经营 / 个人 |
| 系统管理员 | `#2F4A75` | 系统设置 / 经营概览 / 个人 |
| 读者 | 无侧栏，走浅色门户（`#F7F7F4` 纸底 + 白卡 + 衬线标题） | 水平导航 |

## 7. 响应式

- ≥1200px：侧栏 220px + 4 列看板。
- <768px：侧栏转抽屉，筛选折叠为底部面板，表格转信息卡片（只留编号 / 状态 / 时间 / 负责人），主按钮固定安全区，点击区 ≥44px。
- 移动端原型按 390×780 出稿（`.phone`）。

## 8. 禁止项

- 不用渐变背景（除登录页装饰书脊的透明度层）。
- 不用外链图片；设计稿阶段用纸感占位块，build 阶段替换为 `uploads/seed/**` 本地实拍图。
- 不用纯色块表达状态，不隐藏「数据来源」与「计算口径」。
